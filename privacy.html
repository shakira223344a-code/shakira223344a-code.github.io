Privacy Policy

Last updated: October 28, 2026

My Uploader is a personal tool operated by its owner for use with the owner's own Google accounts only.

Data accessed

The app accesses Google user data only through the scopes the user explicitly grants, solely to perform uploads and related actions requested by the user.

Use and storage

OAuth tokens are stored locally on the owner's server and are never sold, shared with, or transferred to third parties. Google user data is not used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
